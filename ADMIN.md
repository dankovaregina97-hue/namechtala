# Управление сайтом (админка)

Админка открывается по адресу **`/admin/`** (например, `https://ваш-сайт/admin/`).
Она правит файлы в папке `content/` прямо в репозитории GitHub. После сохранения
хостинг (Vercel) сам пересобирает сайт — изменения появляются примерно через минуту.

## Что можно менять

| Раздел | Что внутри |
| --- | --- |
| Услуги и цены | категории, услуги, длительность, цена (в т. ч. «от») |
| Мастера | направления, мастера, должности, фото |
| Работы (фото) | галерея работ мастеров по направлениям |
| Тексты страниц | «Главная», «О нас» |
| Контакты и настройки | название, Telegram/WhatsApp/Instagram, телефон, адрес, Яндекс Карты, 2ГИС, код записи DIKIDI |

## Как войти (один раз)

1. Войдите в GitHub под аккаунтом, у которого есть права записи в репозиторий.
2. Откройте https://github.com/settings/personal-access-tokens/new
3. Заполните:
   - **Resource owner** — владелец репозитория (`dankovaregina97-hue`);
   - **Repository access** → *Only select repositories* → `namechtala`;
   - **Permissions → Repository permissions → Contents: Read and write**;
   - срок действия — на ваше усмотрение (после окончания создайте новый токен).
4. Нажмите **Generate token** и скопируйте токен (он показывается один раз).
5. Откройте `/admin/` → **Sign In Using Access Token** → вставьте токен.

Токен хранится только в вашем браузере. Никому его не передавайте: с ним можно менять сайт.

## Фото

- **Фото мастера** — раздел «Мастера»: в карточке мастера поле «Фото».
- **Фото работ** — раздел «Работы (фото)»: «Добавить фото», выберите файл, при желании укажите мастера и направление.

Загруженные фото сами сжимаются в WebP до 1600 px по длинной стороне и сохраняются в `public/uploads/`
(коммитом в репозиторий). Поэтому можно загружать фото с телефона как есть (до 15 МБ каждое).

Советы: загружайте только лучшие работы; репозиторий GitHub комфортно держит до ~1 ГБ,
после сжатия это сотни и сотни фото.

## Локальная разработка

`npm install`, затем `npm run dev` — перед запуском скрипт копирует панель в `public/admin/`.
